Booksy widget embed test

Each frame below loads Booksy’s own booking widget for one business ID. If a frame shows that barber’s services and open times, the embed works for them. If it stays blank or shows an error, that ID has no widget enabled. Check this on a phone too — that is where most walk-in traffic decides.

Widget URL pattern: https://booksy.com/widget-2021/instagram/index.html?country=us&lang=en&id=<BUSINESS_ID>
Business IDs come from each barber’s public Booksy profile URL. The shop’s ID (1413101) came from resolving link.booksy.com/GenuineThroneBarbershop.
